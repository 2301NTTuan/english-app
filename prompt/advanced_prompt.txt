```ts
  tags: string[]
}
```

# DEVELOPMENT PRIORITY

If implementing everything at full scale in one run becomes too large, use this priority order:

```text
1. Data architecture and validation
2. Placement Test
3. Personalized Learning Path
4. Exercise Generator
5. Grammar detailed lessons
6. A1 vocabulary
7. A2 vocabulary
8. B1 vocabulary
9. B2 vocabulary
10. C1 vocabulary
11. C2 vocabulary
12. Idioms / phrasal verbs / collocations expansion
13. Visual polish
```

Do not sacrifice correctness to hit arbitrary content counts.

A smaller validated dataset is better than thousands of incorrect entries.

However, continue implementing autonomously as far as practical during this run.

Do not stop after producing a plan.

Start by inspecting the current repository and existing learning/data architecture.
