# 3. Product goal

The application should become a serious personal English-learning application called:

**English Mastery**

It should support learners from:

```text
A1 → A2 → B1 → B2 → C1 → C2
```

The app should not behave like a static dictionary.

It should behave like a learning system.

Core philosophy:

```text
Due Reviews
    ↓
Weak Knowledge
    ↓
Past Mistakes
    ↓
New Knowledge
```

The system should continuously decide:

* what the learner should review
* what the learner is weak at
* how many new words should be introduced
* which grammar concepts are ready to learn
* what type of exercise should be shown
